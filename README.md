# Flot

Flot is a JavaScript plotting library for jQuery, focused on simple usage,
attractive looks and interactive features. Read more at the website:
<http://www.flotcharts.org/>

This repository is the ThingsBoard-maintained fork of
[flot](https://github.com/flot/flot), used by the ThingsBoard platform. It
carries a few small fixes on top of the upstream 0.9 branch, which upstream
never released.
